| **1** | **B** | Cognitive execution loops distinguish true agents from static conversational models by allowing autonomous observation-action cycles. |
| **2** | **C** | The ReAct paradigm specifies the iterative cycle: Thought (reasoning), Action (tool selection), and Observation (environment feedback). |
| **3** | **B** | Gemini 1.5 Pro features an expansive 1M to 2M+ token context window, excelling at large multimodal document analysis. |
| **4** | **B** | Claude 3.5 Sonnet is recognized for exceptional coding accuracy, structured tool calling precision, and native computer-use capabilities. |

| **7** | **C** | An Observation in agent theory is the runtime output returned to the language model after executing a requested Action in the external environment. |
| **8** | **A** | LLMs are probabilistic token generators; validating parameters against schemas prevents invalid types or missing parameters from crashing system code. |
| **9** | **B** | Level 2 in the course taxonomy encompasses visual workflow automation and node-based low-code canvases such as n8n, Langflow, and Flowise. |
| **10** | **C** | Robust agents treat errors as informative observations, injecting the diagnostic message into context so the agent can self-correct or select an alternative tool. |
| **11** | **B** | The scratchpad/trajectory serves as short-term episodic memory, ensuring the agent retains context of previous attempts and observations within the session. |
| **12** | **B** | Claude's Computer Use API allows the model to perceive UI visually and interact with desktop software via mouse and keyboard commands. |
| **13** | **B** | Level 1 foundation assistants offer powerful cognitive and tool-formulation capabilities, but require an external host loop or user interaction to actually execute actions. |
