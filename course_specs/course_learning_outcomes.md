# AINT 2050: Course Learning Outcomes & Competency Alignment

## Course Overview
**Course Title:** Applied AI Agent Architectures: From Conversational Spark to LangGraph Systems  
**Course Number:** AINT 2050  
**Credits:** 3 Semester Credits  
**Delivery Format:** 8-Week Accelerated Hybrid (150 minutes Synchronous Active Learning + 150 minutes Asynchronous Guided Study per week)  
**Target Environment:** Python 3.11+, LangGraph, n8n, Langflow, Gemini API, Anthropic Claude API  

---

## Pedagogical Philosophy: The Spectrum of Agent Autonomy
Modern artificial intelligence is transitioning from passive text completion into **active, goal-directed autonomous agency**. AINT 2050 equips students with the theoretical frameworks and hands-on engineering capabilities to architect agents across the entire agency spectrum:

1. **Level 1 — Conversational Foundation Assistants (Prompt-Driven):** Leveraging foundation models (Google Gemini Spark, Anthropic Claude) through system prompts, few-shot prompting, and single-turn tool calls.
2. **Level 2 — Visual & Low-Code Workflow Automation (Flow-Driven):** Orchestrating multi-step agent pipelines, document processing, and API webhooks visually using platforms like **n8n** and **Langflow**.
3. **Level 3 — Code-First Stateful Agent Graphs (Graph-Driven):** Engineering production-grade cyclical, stateful agent systems using **LangGraph**, where state machines, conditional routing, human-in-the-loop interrupts, and persistent memory enable enterprise reliability.
4. **Level 4 — Multi-Agent Systems & Swarms (Collaborative):** Orchestrating specialized subagents under hierarchical supervisor architectures to decompose complex enterprise objectives.

---

## Master Course Learning Outcomes (CLOs)
Upon successful completion of this course, students will be able to:

1. **CLO 1 (Agent Taxonomy & Prompt Architectures)**: Differentiate levels of agent autonomy and implement structured reasoning loops (ReAct, Plan-and-Solve) using foundation models (Google Gemini, Anthropic Claude). *(Bloom's: Applying / Analyzing)*
2. **CLO 2 (Visual & Low-Code Orchestration)**: Construct, debug, and automate multi-step agentic workflows and API integrations using visual platforms (n8n, Langflow). *(Bloom's: Applying)*
3. **CLO 3 (Stateful Graph Engineering)**: Architect cyclical, stateful agent workflows using code-first frameworks (LangGraph), defining typed states, routing nodes, conditional edges, and persistent checkpointers. *(Bloom's: Creating)*
4. **CLO 4 (Tool Integration & Action Dispatch)**: Design and execute robust tool-calling schemas (JSON Schema / Pydantic) with dynamic discovery, parameter validation, and exception fallback handling. *(Bloom's: Creating / Evaluating)*
5. **CLO 5 (Human-in-the-Loop & Safety Governance)**: Implement state interrupts, review breakpoints, permission gating, and rate limiting to ensure secure, deterministic agent behavior. *(Bloom's: Evaluating)*
6. **CLO 6 (Multi-Agent Systems & Evaluation)**: Coordinate multi-agent collaborative networks (hierarchical supervisors, specialized workers) and benchmark performance via automated evaluation suites. *(Bloom's: Creating / Evaluating)*
